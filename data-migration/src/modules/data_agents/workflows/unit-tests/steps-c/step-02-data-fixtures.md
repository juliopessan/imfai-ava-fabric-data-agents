# Step 02 — data-fixtures

## Objetivo

Definir dados de exemplo (fixtures) quando necessário.

## Instruções

1) Se o projeto já tem dataset de exemplo, referencie.

2) Caso contrário, crie um stub `fixtures.md` dentro de `tests/` descrevendo como gerar dados de teste.

3) Pare e aguarde **[C] continuar**.
