# Task: Run Migration Wave

## Objective

Execute one migration wave safely and produce a traceable execution report.

## Pre-Checks

1. Gate 2 approved.
2. Rollback path validated.
3. Quality and reconciliation criteria defined.
4. Stakeholder approval for execution window.

## Execution Steps

1. Run pre-flight checks.
2. Execute DDL and ETL in planned order.
3. Run quality checks.
4. Trigger reconciliation checks.
5. Capture results, issues, and remediation actions.

## Outputs

- wave-report.md
- documentation/execution-log.md
- tests/results-summary.md
