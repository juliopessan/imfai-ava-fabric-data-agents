# Step 03 — tests

## Objetivo

Gerar testes mínimos: constraints, DQ e comparação (quando aplicável).

## Instruções

1) Crie stubs de testes (arquivos) dentro de `tests/`.

2) Inclua pelo menos:

   - Um teste de contagem/volume
   - Um teste de nullability (campo obrigatório)
   - Um teste de integridade (FK ou uniqueness)

3) Pare e aguarde **[C] continuar**.
