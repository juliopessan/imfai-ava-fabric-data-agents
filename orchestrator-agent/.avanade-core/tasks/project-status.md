# Project Status Task

**Task ID:** project-status  
**Agent:** Orchestrator  
**Version:** 1.0

---

## Purpose

Generate a comprehensive status report showing the current project phase, completed artifacts, pending items, and recommended next steps.

---

## Execution Steps

### Step 1: Scan Workspace for Artifacts

Search the workspace for the following artifact categories:

**UPSTREAM Artifacts:**
- [ ] `problem-statement.md` or similar
- [ ] `kpis.md` or KPI documentation
- [ ] `analytical-questions.md` or requirements
- [ ] `sttm.md` or Source-to-Target Mapping
- [ ] `dq-initial.md` or initial Data Quality rules

**MIDSTREAM Artifacts:**
- [ ] `architecture.md` or AOD/DDS documentation
- [ ] `data-model.md` or logical model
- [ ] `decisions.md` or architectural decisions
- [ ] `dq-rules.md` or Data Quality rules
- [ ] `monitoring-spec.md` or observability spec

**DOWNSTREAM Artifacts:**
- [ ] `ddl/` folder with table definitions
- [ ] `etl/` folder with transformation scripts
- [ ] `tests/` folder with unit tests
- [ ] `documentation/` folder with docs
- [ ] Gate reports

### Step 2: Determine Current Phase

Based on artifacts found:

```
IF no UPSTREAM artifacts found:
  → Phase: NOT STARTED
  → Next: Start with DataStrategist

IF UPSTREAM incomplete:
  → Phase: UPSTREAM (In Progress)
  → Next: Complete missing UPSTREAM artifacts

IF UPSTREAM complete AND Gate 1 not passed:
  → Phase: UPSTREAM (Ready for Gate 1)
  → Next: Run *gate-1 validation

IF Gate 1 passed AND MIDSTREAM incomplete:
  → Phase: MIDSTREAM (In Progress)
  → Next: Complete missing MIDSTREAM artifacts

IF MIDSTREAM complete AND Gate 2 not passed:
  → Phase: MIDSTREAM (Ready for Gate 2)
  → Next: Run *gate-2 validation

IF Gate 2 passed AND DOWNSTREAM incomplete:
  → Phase: DOWNSTREAM (In Progress)
  → Next: Complete missing DOWNSTREAM artifacts

IF DOWNSTREAM complete AND Gate 3 not passed:
  → Phase: DOWNSTREAM (Ready for Gate 3)
  → Next: Run *gate-3 validation

IF Gate 3 passed:
  → Phase: PRODUCTION READY
  → Next: Deploy or start new iteration
```

### Step 3: Generate Status Report

Use the template `status-report-tmpl.yaml` to generate report.

**Output file:** `{output_folder}/status-reports/status_{date}_{time}.md`

## Notes

- Always scan the entire workspace, not just specific folders
- Look for variations in file names (e.g., "problem_statement", "ProblemStatement")
- Check for artifacts in output folders of other agents
- Update status based on file modification dates
