# 📦 Inventory Outputs

This folder contains all artifacts generated by the **InventoryScout Agent (Scout 🔍)**.

---

## Standard Artifacts

| Artifact | Description | Format |
|----------|-------------|--------|
| **inventory-map.md** | Complete file structure, statistics, hot spots | Markdown |
| **dependency-graph.json** | Graph of dependencies (nodes + edges) | JSON |
| **asset-catalog.md** | Catalog of all data assets | Markdown |
| **tech-stack-detected.md** | Technologies, versions, frameworks | Markdown |
| **lineage-map.md** | Data lineage and transformation chains | Markdown |
| **knowledge-graph.json** | Structured knowledge graph | JSON/GraphML |
| **inventory-report.md** | Executive summary for stakeholders | Markdown |

## Usage

1. Run InventoryScout commands to generate artifacts
2. Artifacts are saved here automatically
3. Share `inventory-report.md` with stakeholders
4. Use JSON/CSV exports for downstream processing
5. Import `knowledge-graph.json` into Neo4j or Gephi for visualization
