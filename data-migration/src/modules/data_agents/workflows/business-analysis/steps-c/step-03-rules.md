# Step 03 — rules

## Objetivo

Converter regras de negócio em regras técnicas rastreáveis.

## Instruções

1) Em `analytical-questions.md`, adicione uma seção `## Regras de Negócio → Regras Técnicas`.

2) Para cada regra técnica, inclua:

   - ID (ex.: BR-001)
   - Descrição
   - Campo(s) impactados
   - Tipo (validação, derivação, filtro)
   - Severidade sugerida (warn/block)

3) Pare e aguarde **[C] continuar**.

## Menu

- [C] Continuar para Step 04 (sttm)
- [X] Sair
