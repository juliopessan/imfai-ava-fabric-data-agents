# Step 02 — validate

## Objetivo

Checar checklist do Gate 1 e determinar PASS/FAIL.

## Instruções

1) Em `gate-1-report.md`, adicione `## Checklist` e liste:

   - `✅` se arquivo existe
   - `❌` se arquivo não existe

2) Regra de decisão:

   - **PASS** somente se todos os 5 artefatos existirem.
   - Caso contrário, **FAIL**.

3) Adicione `## Resultado` com:

   - `Status: PASS|FAIL`
   - `Gaps:` lista de artefatos ausentes

4) Pare e aguarde **[C] continuar**.

- [C] Continuar para Step 03 (report)
- [X] Sair
