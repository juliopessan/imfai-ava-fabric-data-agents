## 🔄 Workflow: Adding Session Notes

### **After Every Session**
1. **Capture**: Key decisions & action items
2. **Create file**: `SESSION-SUMMARY-YYYY-MM-DD.md` (in this folder)
3. **Share**: With attendees for review
4. **Finalize**: Within 24 hours
5. **Archive**: Move older sessions to subfolder if needed

### **Lessons Learned**
1. **Identify**: Key learning from session
2. **Document**: In LESSONS-LEARNED-LOG.md
3. **Tag**: For future search
4. **Share**: Reference in related projects

### **Naming Convention**
- Sessions: `SESSION-SUMMARY-YYYY-MM-DD.md`
- Lessons: `LESSONS-LEARNED-LOG.md` (single file, append-only)
- Examples:
  - ✅ `SESSION-SUMMARY-2026-06-18.md`
  - ✅ `SESSION-SPRINT1-KICKOFF-2026-06-25.md`
  - ❌ `session.md` (missing date)
