## Decision Logic

### PASSED Criteria

All of the following must be true:
- architecture.md exists and is complete
- data-model.md exists and is complete
- dq-rules.md exists and is complete
- sttm.md exists

### BLOCKED Criteria

Any of the following:
- Any required artifact missing
- Artifact exists but is incomplete (placeholders remaining)
- Gate 2 explicitly failed by Orchestrator
