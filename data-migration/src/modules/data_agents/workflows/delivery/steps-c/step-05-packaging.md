# Step 05 — packaging

## Objetivo

Organizar arquivos em pastas versionáveis e gerar README de execução.

## Instruções

1) Crie/atualize:

   - `{artifacts_root}/{project_code}/implementation-artifacts/README.md`

2) Inclua:

   - Pré-requisitos
   - Ordem de execução
   - Onde ficam logs
   - Como rodar testes (link para `tests/`)

3) Adicione ao final:

   - `---`
   - `Generated by: delivery`
   - `Date: <ISO timestamp>`

4) Pare.
