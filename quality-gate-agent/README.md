# ✅ Quality Gate Agent

> **AI-Agent Migration Factory™ — Code Quality Validation & Testing**

---

## Overview

The **Quality Gate Agent** validates the quality of generated code ensuring syntactic correctness, semantic equivalence with legacy, best practices compliance, and passes all unit tests. Acts as the gatekeeper — no code reaches production without **Vera's** approval.

Every pipeline generated by **Coda ⚙️** must pass through Vera's multi-dimensional quality analysis before moving forward. The validation combines static analysis, dynamic testing, LLM-based semantic comparison, and performance profiling to produce a single, weighted quality score that determines the pipeline's fate: **approved**, **rejected**, or **needs_review**.

## Integration Map

### Upstream (Inputs)

| Agent             | Artifact                              | Description                                          |
|-------------------|---------------------------------------|------------------------------------------------------|
| **Coda ⚙️**       | `generated-code/{pipeline_id}.py`     | Generated target platform code for validation        |
| **Coda ⚙️**       | `generated-tests/{pipeline_id}_test.py` | Unit tests generated alongside the code            |
| **Logan 🧠**      | `pseudocode/{pipeline_id}.json`       | Original pseudocode for semantic equivalence check   |

### Downstream (Outputs)

| Agent               | Artifact                        | Condition   | Description                                    |
|---------------------|---------------------------------|-------------|------------------------------------------------|
| **Phoenix 🔧**      | `validation-report/*.json`      | `rejected`  | Report sent for self-healing and remediation   |
| **Balance ⚖️**      | `validation-report/*.json`      | `approved`  | Report sent for reconciliation and sign-off    |

## How It Works

```
┌──────────────────────────────────────────────────────────┐
│                   QUALITY GATE FLOW                      │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  1. Receive code + tests from Coda ⚙️                    │
│  2. Load pseudocode from Logan 🧠                        │
│  3. Run validation pipeline:                             │
│     ├─ Syntax Check (Python AST parse)                   │
│     ├─ Lint Analysis (Pylint + Flake8 + mypy)            │
│     ├─ Semantic Equivalence (LLM comparison)             │
│     ├─ Test Execution (pytest + coverage)                │
│     ├─ Performance Analysis (Spark EXPLAIN)              │
│     └─ Security Scan (Bandit)                            │
│  4. Calculate weighted quality score                     │
│  5. Determine decision:                                  │
│     ├─ score ≥ 8.0 → APPROVED ✅                         │
│     ├─ score 6.0–7.9 → NEEDS_REVIEW ⚠️                  │
│     └─ score < 6.0 → REJECTED ❌                         │
│  6. Route to downstream agent                            │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

## Quality Score Breakdown

| Dimension         | Weight | Tool / Method                     | Pass Criteria          |
|-------------------|--------|-----------------------------------|------------------------|
| **Syntax**        | 15%    | Python AST, compile check         | Zero syntax errors     |
| **Lint**          | 10%    | Pylint, Flake8, mypy              | ≤ 10 warnings          |
| **Semantic**      | 30%    | LLM comparison + pseudocode diff  | Confidence ≥ 0.90      |
| **Tests**         | 25%    | pytest execution + coverage       | 100% pass, ≥ 80% cov  |
| **Performance**   | 10%    | Spark EXPLAIN, cost estimation    | No regressions         |
| **Security**      | 10%    | Bandit scan                       | No high/critical       |

---

## Decision Matrix

| Score Range | Decision       | Action                                                 |
|-------------|----------------|--------------------------------------------------------|
| ≥ 8.0       | ✅ APPROVED     | Route to Balance ⚖️ for reconciliation                 |
| 6.0 – 7.9   | ⚠️ NEEDS_REVIEW | Escalate to human reviewer with detailed report        |
| < 6.0       | ❌ REJECTED     | Route to Phoenix 🔧 for self-healing with failure details |

## Quick Start

```bash
# Full validation of a pipeline
@quality-gate *validate --pipeline=PL_CUSTOMER_MASTER

# Check semantic equivalence only
@quality-gate *semantic-check --pipeline=PL_CUSTOMER_MASTER

# Run tests only
@quality-gate *run-tests --pipeline=PL_CUSTOMER_MASTER

# Check performance
@quality-gate *check-performance --pipeline=PL_CUSTOMER_MASTER

# Get final score
@quality-gate *score-pipeline --pipeline=PL_CUSTOMER_MASTER
```
