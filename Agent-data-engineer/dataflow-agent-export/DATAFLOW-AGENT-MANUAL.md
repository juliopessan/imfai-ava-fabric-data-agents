## 🎯 Overview

**DataFlow** is a specialized data engineering agent that assists in creating, optimizing, and maintaining data pipelines. It follows the **Medallion** architecture (Bronze/Silver/Gold) and implements data quality best practices.

### When to Use This Agent
- Create data ingestion pipelines
- Generate DDL scripts (table definitions)
- Develop ETL/ELT (transformations)
- Validate data quality
- Optimize pipeline performance
- Document data architectures
- Audit production (checklists)

### 4. `*create-etl`

**What It Does:**  
Generates SQL scripts for data transformation between layers (Landing → Silver → Gold).

**Purpose:**  
- Implement business logic
- Validate data quality
- Clean and standardize data
- Create aggregations
- Separate valid/invalid records
- Apply Type 2 SCD (Slowly Changing Dimensions)

**Required Parameters:**
1. **Pipeline name**
2. **Transformation rules** (cleansing, standardization)
3. **Validation rules** (nulls, types, ranges)
4. **Aggregations** (SUM, COUNT, AVG, etc)
5. **Time dimensions** (daily, monthly)
6. **Load type** (full, incremental)

**How to Use:**
```
*create-etl
```

**Generated Scripts:**

**1. Landing → Silver (Validation + Cleansing)**
```sql
-- Quality validation
INSERT INTO SILVER.{PIPELINE}
SELECT 
    *,
    CASE 
        WHEN {validations} THEN 'VALID'
        ELSE 'INVALID'
    END AS quality_flag,
    {error_messages} AS quality_errors
FROM LANDING.{PIPELINE}
```

**2. Silver → Gold (Aggregations)**
```sql
-- Aggregations by status/day/dimension
INSERT INTO GOLD.{PIPELINE}_DAILY
SELECT 
    DATE(date_column),
    COUNT(*),
    SUM(amount),
    AVG(value)
FROM SILVER.{PIPELINE}
WHERE quality_flag = 'VALID'
GROUP BY DATE(date_column)
```

**3. Reject Handling**
```sql
-- Invalid records for analysis
INSERT INTO REJECT.{PIPELINE}_REJECTS
SELECT * FROM SILVER.{PIPELINE}
WHERE quality_flag = 'INVALID'
```
