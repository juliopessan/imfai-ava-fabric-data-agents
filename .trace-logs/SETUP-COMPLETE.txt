Step 2: Copy the TraceWriter Helper Class
  → Creates .trace-logs directory structure automatically
  → Places traces in correct subdirectory based on type

Step 3: Write Your First Trace
  
  from trace_writer import write_trace
  
  write_trace(
    trace_type="agent_execution",
    context={
      "category": "agents",
      "agent_id": "my-agent",
      "wave": "Financeiro-wave2",
      "gate": 1
    },
    operation={
      "name": "spawn_agent",
      "duration_sec": 45.23,
      "status": "success"
    },
    metrics={
      "tokens_in": 2048,
      "tokens_out": 1024,
      "cost_usd": 0.15
    }
  )

Step 4: Query Your Traces
  
  import json
  from pathlib import Path
  
  total_cost = sum(
    event.get("metrics", {}).get("cost_usd", 0)
    for f in Path(".trace-logs").rglob("*.jsonl")
    for event in [json.loads(line) for line in open(f)]
  )
  print(f"Cost: ${total_cost:.2f}")

Each line in a JSONL file is a complete trace event:

{
  "timestamp": "2026-06-18T14:32:15.123456Z",           ISO 8601 UTC
  "trace_id": "tr_bdf3e2c1-8f9a-42eb-b012-1a2b3c4d5e6f", UUID v4
  "trace_type": "agent_execution",                      One of 6 types
  "context": {
    "category": "agents",                               agents|workflows|etl|gates|migrations|analytics
    "agent_id": "migration-coordinator",
    "wave": "Financeiro-wave2",
    "gate": 1,
    "tags": ["critical", "gate-1-validation"]
  },
  "operation": {
    "name": "spawn_agent",
    "duration_sec": 45.23,
    "status": "success",                                success|failure|partial|timeout
    "error": null
  },
  "metrics": {
    "tokens_in": 2048,
    "tokens_out": 1024,
    "artifacts_generated": 3,
    "artifact_size_kb": 245,
    "cost_usd": 0.15
  },
  "metadata": {
    "source": "migration-coordinator.py:1245",
    "version": "1.0.0",
    "environment": "production"
  }
}

💡 BEST PRACTICES

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ DO:
  ✓ Always include ISO 8601 UTC timestamp with millisecond precision
  ✓ Use UUID v4 for trace_id (with tr_ prefix)
  ✓ Include wave, gate, agent_id in context
  ✓ Add tags for quick filtering
  ✓ Append traces (never modify existing records)
  ✓ Create new file per day per context
  ✓ Include meaningful operation names
  ✓ Add all available metrics

❌ DON'T:
  ✗ Don't store PII (filter before logging)
  ✗ Don't modify existing traces (WORM pattern)
  ✗ Don't include large objects (reference IDs instead)
  ✗ Don't mix trace types in same file
  ✗ Don't use free-text fields where structured fields exist
  ✗ Don't append to old files (rotate daily)
