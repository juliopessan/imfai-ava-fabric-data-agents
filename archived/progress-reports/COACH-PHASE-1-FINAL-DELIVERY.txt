🎓 THE 6 ANTI-PATTERNS (WHAT COACH DETECTS)

1️⃣  WAVE COMPLETION (-15 pts)
    ├─ Trigger: Entity coverage < 90%
    ├─ Scenario: Discovered 127 entities, only mapped 98
    ├─ Action: Gate blocks until all entities reviewed
    └─ Benefit: Catch gaps before downstream tables

2️⃣  STTM STABILITY (-10 pts)
    ├─ Trigger: STTM regenerated > 2× in 2 hours
    ├─ Scenario: Stakeholder feedback → rework 3 times
    ├─ Action: Recommends clarification before rework
    └─ Benefit: Prevent thrashing on unstable requirements

3️⃣  MODEL OVERRELIANCE (-5 pts)
    ├─ Trigger: GPT-4/Opus on parametric tasks
    ├─ Scenario: Using expensive model for simple mapping
    ├─ Action: Suggest Claude Haiku (88% cost reduction)
    └─ Benefit: Optimize model cost-to-value

4️⃣  CONTEXT BLOAT (-10 pts)
    ├─ Trigger: Context > 70% OR artifact > 40KB
    ├─ Scenario: Gate 1 artifact 53KB (77% of window)
    ├─ Action: Recommend artifact split
    └─ Benefit: Prevent context limits blocking future gates

5️⃣  SILENT EXECUTOR FAILURE (-30 pts) 🚨
    ├─ Trigger: Output < 1000 tokens AND artifact < 10KB
    ├─ Scenario: Executor says "success" but wrote nothing
    ├─ Action: Auto-trigger self-healing agent
    └─ Benefit: Catch failures PRE-Gate3 (not post-mortem)

6️⃣  GATESCORE REGRESSION (-20 pts)
    ├─ Trigger: Score drops > 5% WoW
    ├─ Scenario: Wave 2 (0.88) → Wave 3 (0.82)
    ├─ Action: Alert on trend, recommend investigation
    └─ Benefit: Detect process degradation early

🔄 HOW COACH WORKS (The Feedback Loop)

Agent executes
    ↓
Telemetry captured (.coach/telemetry/*.jsonl)
    ↓
Gate validates quality
    ↓
Coach detects anti-patterns
    ↓
GateScore adjusted (-15, -10, -5, etc.)
    ↓
Gate decision: approved / conditional / blocked
    ↓
Wave completes
    ↓
Coach analyzes (generates report)
    ↓
Team learns (improves next wave)
    ↓
Skills discovered (reuse patterns)
    ↓
Next wave (iteration 2, improved!)
