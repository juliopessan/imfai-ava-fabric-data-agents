# DataFlow Agent - Demo Outputs

This folder contains demonstration artifacts generated by the DataFlow agent.

## 📁 Folder Structure

```
data-outputs/
├── ddl/              # Table definitions (CREATE TABLE scripts)
├── etl/              # ETL/ELT transformation scripts
├── tests/            # Unit and integration tests
├── profiles/         # Data profiling reports
├── quality/          # Data quality validation results
├── documentation/    # Pipeline documentation
├── optimization/     # Performance analysis reports
└── audits/           # Checklist execution results
```

## 🎯 Naming Convention

All generated files follow the pattern:
```
{type}_{name}_{YYYY-MM-DD_HHmm}.{ext}
```

**Examples:**
- `ddl_landing-tables_2026-01-26_1600.sql`
- `etl_transform-silver_2026-01-26_1600.sql`
- `profile_nyc-taxi_2026-01-26_1600.md`
- `tests_unit-tests_2026-01-26_1600.sql`

## 📊 Demo Data Source

The demo uses NYC Green Taxi data (April-June 2021):
- ~785,000 trip records
- Multiple formats: CSV, Parquet, JSON, TSV
- Located in `../Files/`

## 🚀 Quick Start

To generate demo outputs, activate the DataFlow agent and run:
```
*run-demo
```

Then select a scenario (1-9) or 'A' for full demo.
