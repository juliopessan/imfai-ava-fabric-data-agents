# Step 02 — contracts

## Objetivo

Criar contratos por agente (allow/deny) + inputs + outputs.

## Instruções

1) Em `agent-execution-contracts.md`, adicione `## Contratos por agente`.

2) Para cada agente, declare:

   - `Inputs obrigatórios` (arquivos/artefatos)
   - `Outputs esperados` (arquivos)
   - `Allowed actions`
   - `Denied actions`

3) Agentes mínimos:

   - `data-strategist`, `business-analyst`, `data-solution-architect`, `data-modeler`, `agent-designer`, `data-engineer-exec`, `data-steward`, `orchestrator`, `iteration-improvement` (+ `bi-semantic` se habilitado)

4) Pare e aguarde **[C] continuar**.
