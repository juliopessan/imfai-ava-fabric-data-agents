# Step 03 — metrics

## Objetivo

Definir métricas (definições) e agregações esperadas.

## Instruções

1) Em `data-model.md`, adicione `## Métricas e definições`.

2) Para cada métrica, inclua:

   - Nome
   - Definição
   - Fórmula
   - Grain
   - Dimensões
   - Observações

3) Pare e aguarde **[C] continuar**.
