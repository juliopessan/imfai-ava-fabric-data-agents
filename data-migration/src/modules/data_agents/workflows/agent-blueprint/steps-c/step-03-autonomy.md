# Step 03 — autonomy

## Objetivo

Definir limites de autonomia e escalação humana.

## Instruções

1) Em `agent-blueprint.md`, adicione `## Autonomia e escalação`.

2) Defina categorias mínimas:

   - Ações permitidas automaticamente (safe)
   - Ações permitidas com cautela (needs review)
   - Ações proibidas sem aprovação humana (unsafe)

3) Registre pelo menos exemplos para:

   - alterações destrutivas de schema
   - acesso a dados sensíveis
   - publicação/merge em branch protegida

4) Pare e aguarde **[C] continuar**.
