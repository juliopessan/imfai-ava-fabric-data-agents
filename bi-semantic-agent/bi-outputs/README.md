# BI Outputs Directory

This folder is the **output destination** for all artifacts generated by the InsightForge BI Developer Agent.

## 📁 Required Structure

The agent will **automatically create** this structure when activated or before generating outputs:

```
bi-outputs/
├── README.md                  # This file
├── semantic-models/           # Data model definitions (.tmdl, .md, .yaml)
│   └── .gitkeep
├── dax-measures/              # DAX measure libraries (.dax, .md)
│   └── .gitkeep
├── dashboards/                # Dashboard specs and HTML previews (.md, .html, .yaml)
│   └── .gitkeep
├── reports/                   # Report specifications (.md, .yaml)
│   └── .gitkeep
├── documentation/             # Requirements and technical docs (.md)
│   └── .gitkeep
├── security/                  # RLS configurations (.md, .yaml)
│   └── .gitkeep
├── optimization/              # Performance analysis reports (.md)
│   └── .gitkeep
└── validation/                # Checklist results (.md)
    └── .gitkeep
```

## 🎯 How Outputs Are Generated

1. **On Activation**: Agent verifies this structure exists
2. **During Task Execution**: Outputs saved to appropriate subfolder
3. **During Demo**: All demo artifacts organized here
4. **On Demand**: Use `*setup-outputs` to recreate structure

## 📊 Dashboard Preview

After running `*demo`, you can generate an interactive HTML dashboard preview that opens in your browser.
Use `*generate-html` to create HTML dashboards anytime.

## 🔄 Output Naming Convention

Files are named with timestamps for versioning:
```
{type}_{name}_{YYYY-MM-DD_HHmm}.{ext}
```

**Examples:**
- `semantic-model_sales-analytics_2026-01-22_1430.md`
- `dax-measures_financial-kpis_2026-01-22_1445.dax`
- `dashboard-preview_sales_2026-01-22_1500.html`

## ⚙️ Structure Definition

This structure is defined in:
- `core-config.yaml` → `outputStructure` section
- `bi-developer.chatmode.md` → `output-structure` section
- `setup-output-structure.md` → Task with creation scripts

---

**Note**: This folder starts with `.gitkeep` files. Outputs are generated dynamically by the agent.
