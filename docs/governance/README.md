## 🔄 Workflow: Adding Governance Docs

### **When Adding a File**
1. **Decide**: Is it governance-related? (audit, compliance, quality)
2. **Place it here** in `docs/governance/`
3. **Update this README.md** (add to "Contents" table)
4. **Reference in related folders** (if cross-cutting)

### **Naming Convention**
- Use: `GOVERNANCE-<TOPIC>-<DATE>.md` or `AUDIT-<TOPIC>-<DATE>.md`
- Examples:
  - ✅ `AUDIT-REPORT-2026-06-16.md`
  - ✅ `GOVERNANCE-QUALITY-GATES.md`
  - ✅ `COMPLIANCE-CHECKLIST-2026-06-16.md`
  - ❌ `audit.md` (missing date/topic)

### **Review Cycle**
- Audits: Quarterly (or as needed)
- Compliance: Ongoing monitoring
- Governance: Annual review + updates
- Updates: Always note date of change
