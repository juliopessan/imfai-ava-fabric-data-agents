# Step 03 — kpis

## Objetivo

Definir KPIs/OKRs com baseline, target, fórmula e owner.

## Instruções

1) Crie/atualize o arquivo:

   - `{artifacts_root}/{project_code}/planning-artifacts/kpis.md`

2) Produza uma tabela mínima (pode ser Markdown) com colunas:

   - KPI
   - Descrição
   - Fórmula
   - Baseline
   - Target
   - Janela/periodicidade
   - Owner
   - Fonte de dados

3) Inclua 3–7 KPIs do piloto (ou do seu caso real).

4) Pare e aguarde **[C] continuar**.
